JellyWatcher

Shows a Watchlists page in Jellyfin's menu with each person's JellyWatcher lists and their timelines. People use it with their Jellyfin account; JellyWatcher applies the same rules as signing in with Jellyfin.

The File Transformation plugin is not installed, so the Watchlists page cannot appear in Jellyfin yet. Add the repository https://www.iamparadox.dev/jellyfin/plugins/manifest.json, install File Transformation, and restart Jellyfin.
The address Jellyfin's server uses to reach JellyWatcher, e.g. the container name on the same Docker network. Include any base path.
From JellyWatcher › Integrations › Jellyfin › Jellyfin Plugin. Leave empty to keep the saved key.
Used for “Open in JellyWatcher” links when JellyWatcher has no JW_PUBLIC_URL set.
A Material icon name, e.g. bookmarks, list or movie.

Collections and playlists

People can keep a list in Jellyfin as a collection or a private playlist, in the list's order, so it also shows up in apps like Infuse. The plugin only changes and deletes the collections and playlists it made.

When off, nothing is changed in Jellyfin (existing collections and playlists stay until you remove them below).
Collections are visible to everyone who can see the titles in them. Private playlists are always allowed.
Changes are also applied right away when made on the Watchlists page, and shortly after library scans.

After changing the menu name or turning the page on or off, reload Jellyfin in the browser.
